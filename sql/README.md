# Схема бази даних

Раніше тут лежали `.sql`-файли з DDL для Neon Postgres. Проєкт перейшов на
**Turso (libSQL/SQLite)**, і схема тепер описана декларативно в одному місці:

- **`lib/schema.ts`** — єдине джерело правди (Drizzle ORM, діалект SQLite).
- **`npm run db:push`** — застосовує цю схему до бази з `TURSO_DATABASE_URL`.
- **`npm run db:generate`** — якщо потрібні версіоновані міграції в `drizzle/`.

Старий Postgres-DDL видалено навмисно: він не виконується на SQLite (`jsonb`,
`serial`, `timestamptz`, `ADD COLUMN IF NOT EXISTS`, `DO $$ … $$`), тож тримати
його поруч означало б запрошувати запустити те, що зламається.

Функції `ensure*Table()` у `lib/db.ts` дублюють цю ж схему як запобіжник під час
виконання (запит до порожньої бази сам створює таблиці й повторюється). Якщо
додаєте колонку — оновіть обидва місця.
